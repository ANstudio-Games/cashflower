# Cashflower

[English](README.md) · [Bahasa Indonesia](README.id.md) · 简体中文

Cashflower 是 **ANstudio** 的记账应用，可用于记录收支、管理钱包、跟踪债务，以及设置预算和购买计划。

## 使用方法

### 记录收入与支出

点击 **+**，选择收入或支出，填写金额、标题、分类和日期。如有需要，添加备注后保存。在**交易**页中可以搜索、筛选、编辑或删除记录。

### 管理钱包

从**首页**或**设置**进入钱包管理，添加现金、银行账户或电子钱包。记录交易时选择对应的钱包。钱包间转账不会计入收入或支出。

### 记录应付款与应收款

打开**债务**页，记录您借入或借出的款项。填写姓名、金额和到期日期，并在实际付款时记录还款。

### 设置预算与购买计划

在预算设置中设定每月支出上限。对于计划中的购买，可以创建购买计划、分配资金，并在完成购买时记录支出。

### 查看汇总

在**图表**页查看收入、支出和分类明细。**投资**页用于记录投资交易和查看盈亏，不提供实际交易服务。

### 导出与备份

将报表导出为 PDF 或 CSV。在**设置**中创建 JSON 备份，并保存在应用之外。如需迁移到其他设备，可在新设备上恢复该备份。

财务记录保存在本地。清除应用或浏览器数据、卸载应用或更换设备前，请先备份。核心记账功能可离线使用，但广告和外部分享服务可能需要联网。

可在**设置**中切换界面语言，支持印度尼西亚语、英语和中文。

## 在浏览器中试用

安装当前的 [Node.js LTS 版本](https://nodejs.org/)，下载此项目，并在项目文件夹中打开终端。Windows 用户也可以使用 PowerShell。

```sh
npm install
npm run web
```

打开终端显示的本地地址。使用应用期间，请保持终端运行；按 **Ctrl+C** 可停止服务。

这些命令会在您的电脑上运行网页版本。通知、广告、文件分享和打印等功能可能与 Android 版本不同，或无法在浏览器中使用。首次试用时，建议使用示例数据。
